How this forecast was generated
  1. Approximately 10 years of historical data is collected.
  2. Data is cleaned and transformed.
  3. Multiple forecasting models are trained.
  4. Models are evaluated using historical validation data.
  5. Validation performance determines ensemble weights.
  6. The final forecast combines the model outputs.
This application provides statistical/model-based forecasts for educational and analytical purposes. Forecasts are uncertain and should not be treated as guaranteed future prices or financial advice.
